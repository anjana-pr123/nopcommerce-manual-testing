nopCommerce Manual Testing Project

Project Overview
This project contains manual testing documentation for the nopCommerce demo e-commerce application.

The project focuses on validating major e-commerce functionalities through functional, UI, positive, negative, boundary value, usability, basic performance, and security-oriented testing.

---

🌐 Application Under Test

Application: nopCommerce Demo E-commerce Website

Testing Type: Manual Testing

Test Environment:
- Operating System: Windows 11
- Browser: Google Chrome

---

 Modules Tested

The following modules and functionalities were covered:

- Registration
- Login
- Search
- Categories
- Product Details
- Shopping Cart
- Wishlist
- Currency
- Checkout
- Orders
- Other relevant e-commerce functionalities
